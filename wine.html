One-time setup on this device

The repo is public, so this page can't ship a token — it keeps one in this browser only (localStorage), and calls GitHub directly.
  1. Open github.com/settings/personal-access-tokens/new.
  2. Resource owner: your account. Repository access: Only select repositories → philipraymondh-ctrl/launcher.
  3. Repository permissions: Actions = Read and write, Issues = Read and write. Optionally Secrets = Read-only, which lets this page warn you when the email secrets are missing (it can only ever read their names — no endpoint returns a value).
  4. Expiration: whatever you like — 90 days is fine, you just paste a new one here after.
  5. Generate, copy, paste below.

References are observed, not typed: when two shops list the same bottle, that is the reference. Cuvee, vintage and format are part of the comparison, so a negoce bottle is never scored against a domaine price and a 2012 is never scored against a 2024. A wine seen at one shop only gets a weaker basis and a caveat; one seen nowhere else is reported as NOREF rather than guessed at. Setting a price by hand still overrides everything — it just is not required any more.
